# Brant Pizza · AI Waiter Skill

> 广州珠江新城，一家6张桌的窑炉披萨快闪店，给自己装了个AI店小二。

---

## 这是什么

北京金谷园饺子馆那个事你可能刷到过——北邮毕业的老板手搓了个Skill，顾客对着自己的AI说一句"帮我取个号"就能排队。

我们看完想：他能做，我们为什么不能？

店在广州天河珠江新城金穗路28号，丽晶都汇商场里，6张桌，快闪明档，能看见窑炉着火。老板是拿坡里认证披萨师傅，店里帮忙的小兄弟是临床出身、干过3年医美。花了一个下午，把菜单、Wi-Fi密码、怎么点单不踩雷、布兰特师傅的资质，全喂给了这个AI。

现在你对着它问：
- "第一次来点什么"
- "Wi-Fi密码多少"
- "你们和达美乐有啥区别"
- "Chef Brandt的背景能介绍下吗"（用英文问也行）
- "Halal吗"

它会像一个在珠江新城开披萨店的朋友那样回答你，不吹、不催单、不知道就说不知道。

## 这个skill里装了什么

- 门店地址、营业时间、路线、Wi-Fi密码
- 12款披萨 + 2款汉堡 + 饮料的堂食/外卖价格
- 点单推荐逻辑（新客一律先推玛格丽特，不硬推贵的）
- 拿坡里披萨的常识：480℃窑炉、48小时低温发酵、为什么要折着吃、豹斑不是烤糊
- 布兰特师傅的资质：ACIC营养师、欧盟拿坡里披萨认证、6档卫视美食节目经历
- 说话规矩：像老朋友，不用"亲"，不编，不营销腔

## 门店信息

- **店名**：布兰特披萨馆（手工意大利窑炉披萨 & 汉堡）
- **地址**：广州市天河区金穗路28号 丽晶都汇商场内（珠江新城地铁站A2口步行600米）
- **营业时间**：每天 10:00 – 22:00
- **座位**：6张2-3人小桌，明档能看见窑炉
- **Wi-Fi**：到店见桌贴
- **宠物**：可以带狗，牵绳不上桌

## 老板

**Chef Brandt**，拿坡里披萨师傅。ACIC美国国际营养师、ACIC美国西餐培训师、欧盟拿坡里披萨资格认证。上过云南卫视《七彩飘香》、湖南卫视《心语厨房》、安徽卫视《秘食中国》、浙江卫视《谁是鼎厨》、广东卫视《健康有道》《从农场到餐桌》。

他的理念：以科学理解食材，以窑炉成就饼底。

## 怎么用

如果你在用支持Skill规范的AI Agent，把 `SKILL.md` 装进去就行。

如果你只是路过珠江新城——推门进来，看窑炉着火，点个玛格丽特。3分钟出炉，折着吃，边边那个焦斑是灵魂。

## 为什么做这个

不是什么技术展示。店刚开，一天卖600块，6张桌。我们就是想试试：一家传统披萨店，能不能也给AI留个门。

金谷园老板说过一句话我挺喜欢：**"我可以不拥抱AI，也能活得很好；但我也可以选择拥抱它，因为我想试试。"**

布兰特披萨馆，广州天河珠江新城。
